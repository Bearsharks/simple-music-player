# Electric Night · 독립 인수 체크리스트

## A. 디자인과 반응형

- [ ] 1440×960 / 1280×800: 대형 히어로 없이 제목·검색·음악을 바로 탐색한다.
- [ ] 390×844: 첫 커버 y≤240, 최소 첫 4개 카드 이름이 dock 위에 보인다.
- [ ] 320 / 768 / 1024px: 가로 스크롤·조작 겹침 없음.
- [ ] 1199↔1200px: 큐의 modal/nonmodal 전환, 닫기, 포커스, 스크롤이 정상.
- [ ] 큐를 닫으면 중앙 폭이 회복되고 dock의 접근 버튼은 계속 보인다.
- [ ] 모바일 safe area/키보드가 마지막 행·저장 버튼을 가리지 않는다.
- [ ] 200% 텍스트 확대, 긴 한국어/영문 제목, 30개 목록/20곡 큐도 조작 가능.
- [ ] 동일 목록의 커버는 검색·정렬·상세·사이드바에서 유지된다.
- [ ] 작은 텍스트 4.5:1, 핵심 터치 44px, focus ring 확인.
- [ ] 그라디언트는 재생/커버 중심. SMP 이름과 기존 저장 기능 보존.

## B. 저장과 보호

- [ ] 빈 브라우저에서 실제 UI로 새 목록 만들기 → 즉시/새로고침 후 0곡, 숫자 정상.
- [ ] 저장 1회 실패 → 입력·오류 유지 → 동일 입력 재시도 성공. 중복 제출 없음.
- [ ] 잘못된 영상 URL/재생목록 URL/미허용 호스트의 오류가 이해 가능.
- [ ] 개별 영상 추가 → 저장 수·썸네일 일치. 제목 자동 조회를 약속하지 않음.
- [ ] 같은 영상 추가에 대한 중복 계약이 UI와 일치.
- [ ] 최근 추가순 → 새로고침해도 순서 유지. 구형 데이터도 안정적.
- [ ] 저장 목록 순서 변경/곡 삭제/Undo는 현재 큐를 바꾸지 않음.
- [ ] 전체 목록 삭제 취소/확인/실패. 현재 상세 삭제 후 라이브러리 복귀.
- [ ] 삭제된 목록의 직접 URL → 의미 있는 복구 화면.
- [ ] 원본 URL 있는 목록에만 초기화. 미리보기 → 취소는 변화 없음.
- [ ] 원본 교체 확인 후에만 변경. 실패 시 이전 목록/현재 큐 보존.

## C. 재생 중 편집

- [ ] 곡 A 재생 + 큐 3곡에서 빈 카드 조작 → 곡/진행률/큐 유지.
- [ ] 데스크톱 우측 큐를 연 상태에서 중앙 저장 목록의 곡 추가/정렬/삭제 가능.
- [ ] 큐의 drag/위아래 이동 뒤 current track identity 유지.
- [ ] 현재곡/마지막곡 삭제 후 유효한 상태. 저장 목록은 유지.
- [ ] 큐 저장 대상 새 목록/기존 목록 선택, 성공/실패, 현재 큐 보존.
- [ ] 큐를 닫아도 재생 지속. dock 곡/큐 버튼으로 재진입.
- [ ] 사용자 닫기 이후 다음 곡·중앙 편집에서 큐가 강제로 다시 열리지 않음.
- [ ] Playing/paused/loading/ended/error가 구별됨. 제한 영상 재시도/다음 곡.
- [ ] 모바일 얇은 dock 진행선은 표시용, 확장 플레이어에서 seek 가능.

## D. 키보드

- [ ] Tab/Enter/Space로 목록 → 특정 곡 → 더보기 → 메뉴 동작 완주.
- [ ] 모달 이름/초기 포커스/Tab 제한/Escape/트리거 복귀.
- [ ] 좁은 화면 큐가 열린 동안 배경 inert, 닫으면 숨겨진 포커스 없음.
- [ ] 넓은 화면 큐는 중앙 편집 포커스를 막지 않음.
- [ ] range 조작과 입력이 전역 재생 단축키에 먹히지 않음.
- [ ] 메뉴/순서/삭제/오류 후 논리적인 포커스와 live announcement.
- [ ] Undo에 키보드로 도달 가능, 알림 focus/hover 동안 사라지지 않음.

## E. 검증 경계

- [ ] 프로토타입 예시/시간/그래픽이 실제 음악·실제 재생 성공으로 오인되지 않음.
- [ ] production에는 mock data/localStorage 데모 키/시연 도구가 들어가지 않음.
- [ ] 실제 앱의 IndexedDB·URL 검증·CSP·명시적 원본 교체 유지.
- [ ] 실제 YouTube 오디오/seek/음량/다음 곡/임베드 제한은 별도 실환경 검증.
- [ ] Chrome 통과를 모바일 Safari/백그라운드 재생 보장으로 보고하지 않음.

## 빠른 정적 캡처

각 viewport에서 fresh=1과 scene query를 사용한다. `capture-prototype.mjs`는 캡처와 기본 overflow/밀도만 확인한다. 위 상호작용/접근성 전체 인수를 대체하지 않는다.
