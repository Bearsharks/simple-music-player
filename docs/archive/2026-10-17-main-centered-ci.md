# main 중심 CI 운영

기준 소스: `5ddf2ecdd19db29751790b9bcc9f789339c986ef`.

- 사용자의 승인에 따라 별도 릴리즈 브랜치 없이 main 중심 개발과 수동 배포를 유지한다.
- 특정 이름의 작업 브랜치만 푸시 시 검사하던 예외를 없앤다. PR 검증과 main 통합 후 검증을 기준으로 삼아 작업 브랜치 간 차이와 중복 실행을 줄인다.
- 조기 검증은 Draft PR로 수행한다. 필수 CI 검사와 브랜치 보호는 유지하며 운영 배포는 실행하지 않는다.
- 변경 workflow는 actionlint 1.7.12로 검사했다(shellcheck 제외). 실제 CI 결과는 변경 PR과 Actions 실행 기록을 원본으로 삼는다.
