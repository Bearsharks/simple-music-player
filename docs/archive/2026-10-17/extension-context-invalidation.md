# 확장 컨텍스트 무효화 검증

- 수정 소스: `c07dcf2ae4773eb2c8bb0c7c878b4e9934ea1883`
- 재현 기준: 배포된 v0.3.0. 격리 Chromium에서 확장을 reload한 뒤 기존 YouTube 문서의 링크를 변경하면 `content.js:183`에서 `Extension context invalidated.`가 발생했다.
- 처리 기준: 무효화된 실행 컨텍스트의 감시·통신을 종료하고, 표시 중인 UI에 새로고침 안내를 제공한다. basket을 변경하지 않는다. 일시적 통신 오류와 컨텍스트 무효화는 구분한다.
- 검사: 동기 예외·Promise 거부·runtime ID 소실·storage 예외·일시적 통신 실패 회귀5개 통과. 실제 브라우저의 컨텍스트 무효화, 오류 미발생, basket 보존, 정상 초기화 및 일반 전달 경로를 확인했다.

검수 시 v0.3.1은 게시 전이었다. 기존 탭에 남은 v0.3.0 스크립트에는 새 코드가 소급 적용되지 않으므로 YouTube 새로고침이 필요하다.
