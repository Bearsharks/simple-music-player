# SMP 디자인 개편 — Midnight / Coral

## 사용자 방향

정돈된 현대적 웹앱의 타이포그래피·간격·표면을 사용하고, 음악 라이브러리 탐색과 재생 흐름을 연결한다. Spotify의 로고·대표 녹색·콘텐츠를 복제하지 않는다. 초기 라임안은 사용자 피드백에 따라 폐기했다.

## 시각 체계

- 딥 네이비 캔버스 #0a0f1c, 차분한 블루 패널
- 살구빛 코랄 #ffb49a를 생성·재생·진행률에 제한적으로 사용
- 앨범 대체 커버: 블루·라벤더·샌드. 원본 썸네일을 읽지 못하면 깨진 이미지 대신 대체 커버 유지
- 직접 구성한 CSS 레코드 슬리브/바이닐 그래픽. 외부 브랜드 이미지나 가짜 사용자 목록을 제품에 넣지 않음
- 탐색 레일, 컬렉션 영역, 지금 재생 패널, 고정 재생바의 네 영역

## 반응형과 동작

- 1200px 이상: 사이드바와 오른쪽 대기열을 항상 표시
- 760–1199px: 사이드바 유지, 대기열은 열고 닫는 패널
- 760px 이하: 라이브러리 중심 2열 카드, 고정 미니 재생바, 대기열 드로어
- 재생목록 검색은 브라우저의 저장 목록 필터이며 외부 검색 요청이 아님
- 곡 재생 시 대기열을 열어 플레이어에 접근 가능
- 닫힌 좁은 화면 드로어는 inert/aria-hidden 처리
- 재생 위치/음량은 키보드로 조작 가능한 range 입력 사용
- prefers-reduced-motion 적용

## 보존 범위

IndexedDB 저장, 영상 URL 추가, 저장 목록의 순서/삭제, 대기열 드래그, 원본 URL 초기화, CSP를 유지한다. 로그인·백엔드·도메인 변경은 추가하지 않는다. 미디어 재생 가능 여부와 API 없는 가져오기의 범위는 기존 한계를 그대로 적용한다.

## 변경 진입점

- navigation/pages/Main.tsx: 앱 프레임과 탐색
- navigation/pages/StudioShell.scss: 공통 시각 토큰·라이브러리·반응형
- playlists/ui/playlists/Playlists.tsx: 검색·정렬·카드·빈 상태
- playlists/pages/PlaylistPage.tsx: 상세 화면·곡 추가·정렬·초기화
- player/ui/playerController/ListeningDock.scss 및 PlayerController.tsx: 고정 재생바
- player/ui/playerDetail/PlayerDetail.tsx: 지금 재생/대기열 패널

## 검증

40개 단위/컴포넌트 테스트, 타입 검사, 빌드. CI의 Chromium에서 실제 IndexedDB 저장·새로고침, 1280×800 및 390×844 레이아웃, CSP 차단 검사를 실행했다. 최종 시각 확인에는 1440×960도 추가했다. 스크린샷은 디자인 검증용 데이터이며 사용자 라이브러리가 아니다. YouTube 네트워크는 테스트에서 모의하므로 실제 소리·광고·자동재생·모바일 기기 성능은 증명하지 않는다.
